# Brief
> This module was created for the newbies to implement blockchains locally for learning purposes.
> 
>You can create a blockchain and learn how all of its parts interact with each other. This is great as you will not only get thoery cleared, but also do it yourself.

By using this module, you can do the following:
- Create a blockchain with a couple of nodes running locally on your device.
- Try 51% attack on the blockchain ( should be easy as we have less nodes ).

# Install
Run this command in Terminal :
```bash
pip install blockchainer
```
